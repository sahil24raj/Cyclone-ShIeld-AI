# CycloneShield AI — Research Dataset Package

This is the data package prepared for the CycloneShield AI repository and Antigravity coding agent.

Start with `DATASET_CATALOG.md`.

Validated data is under `data/raw/`.
Invalid/incomplete downloads are intentionally isolated under `data/quarantine/` so an agent cannot accidentally train on them.

The package is **not fully ML-ready yet**: correct Kakinada Open-Meteo data and a numerical IMERG export are still required.
